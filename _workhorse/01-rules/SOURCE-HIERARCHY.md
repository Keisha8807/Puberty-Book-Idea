# SOURCE HIERARCHY

> Determines which information a worker may trust and what happens when sources disagree.

## Authority order

| Rank | Source | Authority |
|---|---|---|
| 1 | Keisha's latest explicit approved decision | Final |
| 2 | `_workhorse/00-command-center/DECISION-LOG.md` + `ACTIVE-CANON.md` | Controlling operational truth |
| 3 | Current active series, character, bridge, and music bibles | Detailed canon |
| 4 | Approved manuscripts and approved visual references | Production truth for their specific episode/asset |
| 5 | Credible external research and qualified human review | Factual evidence—not story canon |
| 6 | Current strategy drafts not yet approved | Proposed only |
| 7 | Old ChatGPT conversations, old planning documents, and source bibles | Archive/idea mining only |
| 8 | 2024 Canva draft and old chapter prose | Archive/reference only |

A newer file date does not automatically give a source more authority. Approval status matters more than timestamp.

## Required source labels

Every work packet and future indexed source receives one label:

- **ACTIVE-CANON:** approved and controlling
- **APPROVED-ASSET:** approved for a specific production use
- **RESEARCH:** factual input requiring evaluation
- **PROPOSED:** awaiting approval
- **ARCHIVE:** historical context or idea mining only
- **SUPERSEDED:** replaced; never use as current truth

## Conflict protocol

When a worker finds conflicting information:

1. Stop the affected portion of work.
2. Quote both conflicting statements.
3. Name each source and its hierarchy rank.
4. Check the Decision Log for a later ruling.
5. Apply the higher-authority source only if the resolution is explicit.
6. If ambiguity remains, create one Approval Queue item.
7. Do not silently blend both versions.
8. Log the final decision and affected files after Keisha approves it.

## Retrieval rule

Workers receive the **smallest sufficient context packet**, not the entire repository.

Example: a Mia hero prompt needs Active Canon, Mia's Lock Block, approved Mia image reference, and style rules. It does not need the CROWN Club ten-book blueprint, old Canva manuscript, or every ChatGPT conversation.

## External research rule

Research answers “what is supported?” It does not decide:

- Character canon
- Voice
- Plot
- Cultural truth
- Product priority
- What Keisha should believe about her own experience

For medical, legal, platform, or market claims, record:

- Source title
- Publisher/organization
- URL or file
- Publication/update date
- Claim supported
- Limitations or disagreement
- Reviewer/approval status

## Output citation

Every specialist's pass-down must list:

- Sources consulted
- Canon version used
- Assumptions made
- Unresolved conflicts
- Facts requiring human review

No source list means the pass is incomplete.
