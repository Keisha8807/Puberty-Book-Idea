## 🧩 CONSISTENCY RULES (the secret sauce)

1. **Never edit the Description Block** — same words every time = same face every time
2. **Swap only [SWAP] parts** — pose, expression, background, action
3. **One style block, forever** — test A vs B on ONE character, lock the winner, use it on everything
4. **For expression sheets:** repeat the description, then list expressions: "expression sheet: curious, confused, emotional, confident, assertive, caring, supportive, prepared, resilient, nurturing, empowered"
5. **For scene art:** keep the character description, change pose/background, and describe the ACTION
