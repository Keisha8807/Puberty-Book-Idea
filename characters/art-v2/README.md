# 🎨 MIA'S PUBERTY PRIMER — CHARACTER VISUAL LIBRARY

> One character, one folder, one approved identity. This library lets Keisha compare every generated option before any face becomes the reference for books, marketing, website assets, or animation-style clips.

## How to add images from ChatGPT or another source

1. Open the character's folder.
2. Open **`00-upload-candidates/`**.
3. Upload the original, highest-resolution image—not a screenshot when the original download is available.
4. Use a helpful name such as `chatgpt-2026-08-18-purple-cardigan.png`.
5. Tell the Workhorse which character folder was updated.
6. The image remains a candidate until Keisha explicitly approves it.

Images generated in another ChatGPT conversation can be used as visual candidates when Keisha generated them or otherwise has the right to use them under the applicable service terms. Do not upload someone else's character art, copyrighted franchise character, or private child's image as our production reference without the necessary rights and permission.

## Folder meanings

| Folder | Meaning |
|---|---|
| `00-upload-candidates/` | Drop new ChatGPT/Arena/other candidate images here |
| `01-candidates/` | Organized options waiting for selection |
| `02-approved/` | Keisha-approved hero/identity assets |
| `03-reference-sheets/` | Turnarounds, expressions, palettes, and model sheets |
| `04-scenes/` | Story and marketing scenes using the locked character |
| `99-superseded/` | Preserved history that must not be used as current reference |

Not every subfolder appears until it contains an asset.

## Selection workflow

```text
Upload or generate candidates
→ compare against the written Lock Block
→ Keisha chooses one identity
→ move winner to 02-approved
→ preserve alternates as candidates or superseded
→ build turnaround + expression row + palette
→ use that approved reference for every future asset
```

## Reference rule

A ChatGPT image can absolutely become the approved reference if Keisha chooses it and it passes canon, age, style, quality, and usage-right checks. Once approved, future generators receive that exact image plus the written Lock Block. A later drifting image never overrides the approved identity.
